# Harini's Birthday Surprise

A mobile-first, static birthday experience built with HTML, CSS, and modern vanilla JavaScript.

## Local preview

Open `index.html` in a browser. A simple local static server can also be used during development.

## Planned structure

```text
.
|-- assets/
|   |-- audio/       # Optional music and short sound effects
|   `-- images/      # Optimized personal photographs and visual assets
|-- css/
|   `-- styles.css   # Mobile-first styling, animation, and accessibility rules
|-- js/
|   `-- main.js      # Stage orchestration and interaction logic
|-- .github/
|   `-- workflows/   # GitHub Pages deployment workflow (added in Phase 10)
`-- index.html       # Static entry point
```

The site has no backend, accounts, analytics, or data collection. All interactions and animations run in the visitor's browser.
